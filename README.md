# jamesronquillo-web-project

## Project 2 - HTML Foundation Page

Webpage Theme:  
My webpage is about golf. It explains why I enjoy the sport, my favorite courses, my practice routine, and the equipment I use. The page includes headers, paragraphs, lists, an image, a table, and links to other resources.

What I Learned:  
- How to structure a webpage using !DOCTYPE html, html, head, and body  
- Adding headings, paragraphs, lists, images, tables, and links  
- Using HTML attributes for styling, like bgcolor, text, link, vlink, font-size, and basic padding/margin  
- Creating a simple navigation bar to link multiple pages  

**Challenges Faced:**  
- Remembering all the different HTML tags and their proper syntax  
- Including multiple elements on the page while keeping it readable and organized  
- Ensuring the image and table displayed correctly without using CSS  
- Adding character encoding to avoid warnings about special characters
